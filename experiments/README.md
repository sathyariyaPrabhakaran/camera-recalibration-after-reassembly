# Experiments

```text
trial,initial_tx_mm,initial_ty_mm,initial_tz_mm,reassembled_tx_mm,reassembled_ty_mm,reassembled_tz_mm,rotation_error_deg,reprojection_rmse_px,processing_time_s,status
```
