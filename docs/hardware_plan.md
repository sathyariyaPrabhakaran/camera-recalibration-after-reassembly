# Low-Cost Hardware Plan

The core project requires no dedicated camera: a laptop/PC webcam is sufficient for the first prototype.

## Purchase order

**Do not purchase hardware until the camera pipeline works.**

1. Print the reference marker on A4 paper.
2. Test detection and pose estimation with the built-in camera.
3. If a physical demonstration is required, add only the minimum controller/servo/mechanical parts.

## Budget ceiling

Team contribution: 4 × ₹250 = ₹1,000 total.

The software prototype should therefore remain laptop-first. Prices are not hard-coded because local availability changes; verify current prices before purchase.

## Physical demonstration concept

A simple servo-mounted camera or marker fixture can simulate a controlled reassembly. The servo is optional and is not part of the core calibration algorithm.
